# Convex Backend (`convex/`)

See `convex/README.md` for full API reference, schema details, and function documentation.

## Critical

- **DO NOT edit `_generated/`** — auto-generated by Convex. Run `npx convex dev` to regenerate.

## Commands

```bash
npx convex dev         # Dev server (syncs schema + functions in real-time)
npx convex deploy      # Deploy to production
npx convex run <fn>    # Run a function manually (e.g., npx convex run migration:migrateUserProfiles)
npx convex logs        # View function execution logs
npx convex dashboard   # Open web dashboard
```

## Auth Pattern

- **Mutations:** Use `requireAuth(ctx)` from `auth.ts` — throws if unauthenticated
- **Queries (optional auth):** Use `getCurrentUser(ctx)` — returns null if unauthenticated

## Key Tables

- `userProfiles` - User data, XP, streaks, stats (Clerk OAuth users)
- `gameSessions` - Story sessions, search, library
- `imageGenerationEvents` - Image generation tracking and analytics

## Schema

Schema defined in `schema.ts` with TypeScript types auto-generated in `_generated/`. Key validators and table definitions are fully typed.
