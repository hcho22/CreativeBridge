# DOCS
We keep all importand docs in .agent folder and keep updating them, in the following structure:

.agent
- Tasks: PRD & implementation plan for each feature
- System: Document the current state of the system (project structure, tech stack, integration points,database schema, and core functionalities such as agent architecture, LLM Layer, etc.)
- SOP: Best practices of execute certain tasks(e.g. how to add a schema migration, how to add a new
page route, etc.)
- README.md: an index of all the documentations we have so people know what & where to look for things

Always update .agent docs after implementing certain feature, to make sure it fully reflects the up to date information.

Before planning any information, always read the .agent/README first to get context.
