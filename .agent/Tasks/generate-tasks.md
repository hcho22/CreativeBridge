# Rule: Generating a Task List from a PRD

## Goal

To guide an AI assistant in creating a detailed, step-by-step task list in Markdown format based on an existing Product Requirement Document (PRD)
The task list should be suitable for a developer to follow for implementation.

## Output

- **Format:** Markdown ('.md')
- **Location:** '/.agent/Tasks/'
- **Filename:** 'TASKS-[PRD-FILE-NAME].md'

## Process

1. **Receive PRD Reference:** The user points the AI to a specific PRD file
